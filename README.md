# Boji · 薄肌周期估算

练到薄肌，大概要多久？

填写当前身体状态和训练情况，对比三种进展情景，了解达到薄肌参考状态的时间范围。

**[在线体验](https://chansir-eng.github.io/boji-office/)** · [模型说明](docs/model.md) · [本地运行](#本地运行)

无需注册 · 浏览器内计算 · 不保存个人数据

![Boji 新版界面：填写当前状态，查看薄肌周期估算](docs/preview.png)

## 从当前状态开始

只需填写六项信息：身高、体重、当前体脂率、年龄、抗阻训练经历和每周力量训练次数。目标统一为薄肌参考状态，无需另外设置。

修改数据后，结果会自动更新。你可以查看：

- **周期范围**：比较保守、中心、较快三种情景，了解不同进展速度下的时间尺度。
- **阶段拆分**：分别查看减脂与增肌阶段，以及中心情景的参考体重。
- **变化趋势**：切换体脂率与体重曲线，对照三种情景的过程。

不确定当前体脂时，可用照片档位作为粗略起点。照片来自不同个体，标注并非人物实测体脂。

## 一个示例

175 cm、78 kg、24% 体脂、28 岁，新手，每周力量训练 3 次。

| 情景 | 减脂阶段 | 增肌阶段 | 总周期 |
| :--- | ---: | ---: | ---: |
| 保守 | 53 周 | 75 周 | 128 周 |
| 中心 | 33 周 | 36 周 | 69 周 |
| 较快 | 23 周 | 21 周 | 44 周 |

这是同一组输入在不同假设下的模型输出。情景范围不是置信区间，也不是个人完成时间的承诺。

## 薄肌如何定义

本工具统一采用两项建模参考：**体脂约 12%**，以及 **标准化 FFMI 达到 20.5**。两项一起判断，避免只看体重或只看体脂。

这组参考不是官方或临床标准，也不意味着所有人都应追求同样的数值。FFMI 反映相对去脂体重，不能直接代表视觉肌肉评分。

模型按自然周分别估算减脂、补足去脂体重及必要的收尾调整，最长模拟 520 周。未规律训练且仍需增肌时，显示“无法估算”。详细公式、情景参数和研究链接见 [模型说明](docs/model.md)。

## 数据与适用范围

个人参数只用于当前浏览器内的计算，不上传、不持久保存；刷新页面后恢复示例。站点无账户、无分析追踪、无后端服务。参考照片从 Pexels 加载，会产生正常的第三方网络请求。

当前模型面向 **18–65 岁健康成年男性**，不提供个体诊疗建议。体脂测量误差、饮食、训练执行和恢复都会影响实际进展，应结合真实变化更新判断。

## 本地运行

纯静态页面，无构建步骤。保留 `index.html` 与 `assets/`，即可使用静态文件服务器预览：

```bash
git clone https://github.com/chansir-eng/boji-office.git
cd boji-office
python -m http.server 8000 --bind 127.0.0.1
```

打开 [http://127.0.0.1:8000](http://127.0.0.1:8000)。计算资源与字体随项目提供，参考照片需要联网。

安装 Node.js 后，可运行不依赖第三方库的回归检查：

```bash
node tests/calculator.test.cjs
```

更多运行、测试、部署与素材说明见 [开发文档](docs/development.md)。
