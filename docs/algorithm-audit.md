# 第二轮算法与科普有效性审计

审计日期：2026-10-26。原版本快照：`ea554af`。范围包括计算模型、页面交互、测试与说明文档。本报告区分可复现的软件行为与研究能够支持的结论，不把两者互相替代。

## 审计结论

Boji可以作为**有条件的教学模型**：展示“假如输入、目标和变化假设成立，计算会怎样变化”。当前资料与实现不支持把它称为经过验证的个人薄肌达标时间预测器。三组结果不是置信区间、成功概率，也不能保证某个人会落在其中。

软件可正确执行一组未校准的假设；这与假设能否解释或预测真实个体是不同的问题。第一轮的432组结果与历史点完全相等，是重构行为一致性的检查，**不是算法科学有效性验证**，也不是对旧代码边界行为的正确性证明。

## 证据核对方法与限制

逐项对照原论文的研究问题、样本、终点和干预长度。Morton、Benito、Garthe核读了原论文PDF；Murphy核读原刊全文；Kouri核对原摘要中的公式；Currier核对原刊/PMC索引缓存中的摘要、方法和讨论。部分直接页面受验证码或403限制，未将摘要核对声称为逐页全文核读。

原页面的八条资料实际为七篇学术论文/综述与一条概念摘要。链接与标题基本对应，但不能让参考文献列表看起来像整套个人预测算法已经获得共同验证。以下只概括其能支持的层级，不摘抄论文作为参数背书。

## 第二轮修复策略

### 科普表达与交互

- 将结果定位为假设下的时间情景模拟，避免把研究均值包装成个人固定增速。
- 情景改称“审慎／中间／乐观”，说明它们是成组的假设，不能推导更快减重就更保肌。
- 结果阶段改称“补足去脂体重”，与“去脂体重不等于肌肉”保持一致。
- 移除通过不同个体照片选择体脂百分比的功能，改为解释测量方法、视觉限制与标准化比较。
- 加入体脂输入±3个百分点的敏感性演示；扰动幅度是教学选择，不是设备误差界线或95%区间。

### 算法与状态

- 输入与轨迹采用BMI18.5保守下界，不把需要跨越该下界的减重轨迹显示为可完成目标。
- 移除每周2/3/4次训练的.87/1/1.04精确加成，仅保留是否规律训练的门控。
- 统一体脂分段附近的浮点容差，避免由数值表示造成非预期断点跳变。
- 减脂最后一步限制到体脂参考，避免完整周步长越过目标；该周仍按一个自然周计数。
- 修复520周终点判定：恰在最后一周完成与仍未完成分别处理。
- 用 `outside-domain`、`unestimated`、`capped`、`complete` 显式区分不适用、未估算、上限与完成，避免只用一个布尔值混淆原因。

## 保留风险

本轮没有把月增长表、去脂损失份额或0.08增脂比换成另一组声称“循证”的固定个人参数，因为现有证据不足以这样做。这些数值继续作为公开、未校准的演示假设。

修复软件边界不会使模型成为个体预测器。固定增长、固定经历、串行顺序、末段零去脂损失及缺少饮食、训练质量、恢复和个体差异仍限制解释。BMI护栏不能替代医疗评估。对真实变化的持续观察也不自动等于对达标日期的验证。
