# 模型与边界

Boji 用三组固定假设比较达到薄肌参考的时间尺度。结果是情景模拟，不是置信区间，也不是经过验证的个体预测。计算实现见 [assets/model.js](../assets/model.js)，输入校验与结果显示见 [assets/app.js](../assets/app.js)。

## 薄肌参考

页面统一采用约 **12% 体脂**与**标准化 FFMI ≥ 20.5**。体脂值来自薄肌概念参考，FFMI 值是本站自设的建模门槛；这组参考不是官方或临床标准，也不意味着所有人都应追求相同数值。数值达标不保证特定外观。

纯模型接受 `targetBF` 和 `targetFFMI` 目标参数，网页使用共享的固定值 `thinMuscleTarget`。

## 体重构成与 FFMI

以体重 `w`（kg）、体脂率 `bf`（%）和身高 `h`（m）计算：

```text
脂肪量 = w × bf / 100
去脂体重 = w − 脂肪量
标准化 FFMI = 去脂体重 / h² + 6.3 × (1.8 − h)
目标去脂体重 = [目标 FFMI − 6.3 × (1.8 − h)] × h²
```

去脂体重包含水、骨、器官与肌肉，不等于纯肌肉。身高标准化系数采用页面所列 Kouri 等人研究中的公式。

## 三种情景

以下数值是可审计的模型参数。尤其是去脂体重损失占比与增长速度，属于工程假设，不能当作研究给出的通用比例或个人增长定律。

| 参数 | 保守 | 中心 | 较快 |
| --- | ---: | ---: | ---: |
| 名义每周减重，占当周体重 | 0.4% | 0.6% | 0.8% |
| 减重中去脂体重损失占比 | 10% | 5% | 0% |
| 新手每四周去脂体重增长 | 0.20 kg | 0.35 kg | 0.50 kg |
| 重新训练者每四周去脂体重增长 | 0.15 kg | 0.28 kg | 0.40 kg |
| 有经验者每四周去脂体重增长 | 0.07 kg | 0.13 kg | 0.22 kg |

训练经历对应页面的“新手 · 规律训练少于 1 年”“重新训练 · 中断后恢复”和“有经验 · 规律训练至少 2 年”。

实际每周减重速度会根据当周体脂乘以下列系数，且不超过当周体重的 0.9%：

| 当周体脂 | 速度系数 |
| --- | ---: |
| > 28% | 1.00 |
| > 22%，≤ 28% | 0.95 |
| > 18%，≤ 22% | 0.88 |
| > 15%，≤ 18% | 0.77 |
| ≤ 15% | 0.62 |

每周去脂体重增长量为表中“四周增长量”除以 4，再乘以训练次数系数：每周 2 次为 `0.87`，3 次为 `1`，4 次及以上为 `1.04`，无法规律训练为 `0`。年龄不参与该公式。

## 模拟顺序

模型按自然周依次计算，单个情景最多模拟 **520 周**：

1. **减脂**：降到目标体脂附近。每周减重不超过剩余脂肪量的 20%；去脂体重损失取“当周减重 × 情景损失占比”和“当周去脂体重 × 0.5%”中的较小值，其余从脂肪量扣除。
2. **补足去脂体重**：按固定周增长量增加，直到达到目标去脂体重附近。每增加 1 kg 去脂体重，同时假设增加 0.08 kg 脂肪。
3. **末段调整**：如体脂仍高于目标，再按对应情景的减重速度扣减脂肪量；此段不扣减去脂体重，周数合并计入界面的减脂阶段。

目标体脂比较保留 `0.0001` 的比例容差，目标去脂体重比较保留 `0.01 kg` 容差。模拟记录初始点及每周状态；趋势图每四周取样，并保留最后一点。

这一顺序用于表达模型假设，不能推导为个人训练安排，也不宣称减脂与增肌能以最大速度同时发生。页面列出的研究与这些工程参数应分别理解。

默认示例为 175 cm、78 kg、24% 体脂、28 岁、新手、每周力量训练 3 次：

| 情景 | 减脂阶段（含末段调整） | 增肌阶段 | 总周期 |
| --- | ---: | ---: | ---: |
| 保守 | 53 周 | 75 周 | 128 周 |
| 中心 | 33 周 | 36 周 | 69 周 |
| 较快 | 23 周 | 21 周 | 44 周 |

这些是模型输出，不是个人完成时间的承诺。

## 结果状态与适用范围

- **已达标**：三种情景均无需继续模拟，显示 0 周；不代表外观已被确认。
- **未估算 / 无法估算**：未规律力量训练，且情景仍需增加去脂体重时，增肌阶段显示“未估算”，总周期显示“无法估算”。若仅需减脂，仍可显示减脂周期。
- **超出范围**：情景达到 520 周上限，不作为可计算的完成日期。总周期范围只统计可完成的情景；全部超限时显示“超出范围”。

页面面向 18–65 岁健康成年男性。年龄只用于范围校验，不调整减重或增长速度。页面接受身高 140–210 cm、体重 35–250 kg、体脂 5%–55%，并进一步拒绝体脂 ≤ 7% 或 BMI 不在 16–48 内的输入。这些是软件适用边界，不构成医学评估。

页面说明未成年人、孕产期、疾病或用药等情况不适用。没有个人纵向体成分数据、执行记录、测量误差和真实能量收支时，模型不能给出确定完成日期。本站不提供个体诊疗建议。

## 视觉参考与数据处理

五张照片来自不同个体，档位百分比不是照片人物的实测体脂。肌肉量、脂肪分布、光线和角度均会影响外观；照片只能作为粗略输入参考。页面也链接了 [Ultimate Performance 真人体脂对照](https://ultimateperformance.com/your-goal/fat-loss/male-fat-loss/male-body-fat-comparison)，并说明不保证每位人物的测量方法。

个人输入只用于当前浏览器内存中的计算，不上传、不持久保存；刷新后恢复示例。站点没有账户、分析追踪或后端。加载 Pexels 照片、打开外部资料时会产生第三方网络请求；照片加载失败不影响档位选择与本地计算。素材来源见 [开发与运行](development.md#素材来源)。
