体脂参考

不确定当前体脂？选择接近的视觉档位，作为粗略起点。

视觉分组，非实测数值

照片为不同个体，百分比并非人物实测体脂。肌肉量、光线和角度都会影响判断，优先参考规范体成分测量。

参考照片的使用说明与来源
重要：五张照片均为独立个体，体脂百分比并非照片人物的测量结果；这只是供你粗略选择起始体脂的视觉档位，不适合医学判断。照片受肌肉量、脂肪分布、光线与角度影响，误差可能较大。优先使用同一设备的规范体成分测量，并结合腰围、体重趋势与标准化照片。需要带有标注的第三方真人图表，可查看 Ultimate Performance 原始真人体脂对照（外部资料，不保证每位人物的测量方法）。照片来自 Pexels：01 · 02 · 03 · 04 · 05。摄影人物不代表赞助或认可本站。

薄肌，不只看体重

本工具用体脂与肌量共同定义薄肌参考状态。

体脂率

薄肌参考：约 12%

本工具采用约 12% 体脂作为概念参考。这不是适用于所有人的健康标准，低于该数值也不自动代表更好。

标准化 FFMI

肌量参考：20.5 及以上

本工具以标准化 FFMI ≥ 20.5 作为有一定肌量的建模门槛，并非官方或临床标准。去脂体重包含水、骨、器官与肌肉，不等于纯肌肉。

计算方式与情景参数

核心运算采用 标准化 FFMI（Kouri 1995）和按体重百分比计算的每周减重速度；增肌速度则设为独立可审计的三情景参数。增肌元分析观察到平均约 13 周增加 1.1 kg 去脂体重，但不能视为所有人的固定增长率。热量赤字会抑制去脂体重增长，因此模型默认以“先减脂、后补肌量”串行计算，不宣称两种适应可满速叠加。

当前情景参数：保守 / 中心 / 较快的名义减重速度分别为每周 0.4% / 0.6% / 0.8%，随着体脂下降自动减速；体重损失中去脂体重占比分别假设为 10% / 5% / 0%（工程假设，非研究给出的通用比例）；新手每四周去脂体重增长分别假设为 0.20 / 0.35 / 0.50 kg，重新训练为 0.15 / 0.28 / 0.40 kg，有经验者为 0.07 / 0.13 / 0.22 kg。越有经验速度可能越慢，但这些不是可验证的个体定律。页面按自然周逐步模拟，最长 520 周。
