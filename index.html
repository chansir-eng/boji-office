03 / 薄肌不是薄薄一层幻想

段子归段子，目标得说清楚

01 · BODY FAT

体脂足够低，线条才可能清晰

采用自定义目标体脂；约 12% 是概念参考，不意味着所有人都应追求同一数值，低于该目标不自动代表更好。

02 · MUSCULARITY

还要有一定去脂体重

用 FFMI = 去脂体重 ÷ 身高² 作跨身高比较。去脂体重包含水、骨、器官与肌肉；FFMI 不等于视觉肌肉评分。

03 · TIME

减脂和增肌分开估算

先计算保留肌量条件下的降脂时间，再计算需要补足的去脂体重。真实训练中可能同时发生，但无法保证叠加收益。

04 / 梗到这里，下面说正经的

公式、依据，以及它算不准的事

计算器能排期，不能给身体开倍速

核心运算采用 标准化 FFMI（Kouri 1995）和按体重百分比计算的每周减重速度；增肌速度则设为独立可审计的三情景参数。增肌元分析观察到平均约 13 周增加 1.1 kg 去脂体重，但不能视为所有人的固定增长率。热量赤字会抑制去脂体重增长，因此模型默认以“先减脂、后补肌量”串行计算，不宣称两种适应可满速叠加。

当前情景参数：保守 / 中心 / 较快的名义减重速度分别为每周 0.4% / 0.6% / 0.8%，随着体脂下降自动减速；体重损失中去脂体重占比分别假设为 10% / 5% / 0%（工程假设，非研究给出的通用比例）；新手每四周去脂体重增长分别假设为 0.20 / 0.35 / 0.50 kg，重新训练为 0.15 / 0.28 / 0.40 kg，有经验者为 0.07 / 0.13 / 0.22 kg。越有经验速度可能越慢，但这些不是可验证的个体定律。页面按自然周逐步模拟，最长 520 周。
